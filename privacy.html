プライバシーポリシー

最終更新: 2026年9月20日

kurashi-labo(以下「当方」)は、Threads API を用いた投稿・返信の運用ツール(アプリ名「スレッズAPI」)および当方が公開するウェブページ(比較ページ・診断ページ等)について、次のとおり個人情報の取り扱いを定めます。

1. 取得する情報

Threads API を通じて取得するのは、当方が管理するアカウント自身の投稿・返信・閲覧数などの統計、ならびに公開投稿の検索結果(投稿ID・本文・投稿者名)です。ウェブページでは、アクセス解析のための情報を取得しません。フォームやログインはありません。

2. 利用目的

取得した情報は、当方のアカウントの投稿・返信の作成と、その効果の測定にのみ利用します。公開投稿の検索結果は、返信する投稿を選ぶためだけに利用し、広告配信やプロファイリングには用いません。

3. 保存と削除

検索結果は取得から7日以内に削除します。当方アカウントの投稿統計は運用改善のために保存します。第三者への提供・販売は行いません。

4. データ削除の依頼

ご自身の投稿に関する情報の削除を希望される場合は、下記の連絡先までお知らせください。確認のうえ速やかに削除します。

5. アフィリエイトについて

当方のウェブページおよびSNS投稿には、楽天アフィリエイト・A8.net 等の広告リンクが含まれることがあります。該当する投稿・ページには「PR」と表記します。

6. 連絡先

GitHub: https://github.com/kurashi-labo(Issues からご連絡ください)
